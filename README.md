# TurkEval thesis progress

Progress dashboard for the M.S. thesis *A Framework for Evaluating the Real-World Performance of Turkish Large Language Models* (Boğaziçi University).

**Live:** https://atahanuz.github.io/thesis-progress/

## Updating progress

1. Open https://atahanuz.github.io/thesis-progress/#edit and click **Update progress**.
2. Adjust the sliders and notes, then click **Copy progress.json**.
3. Click **Open progress.json on GitHub**, replace the file's contents with the copied text, and commit.

GitHub Pages redeploys in about a minute.

You can also edit `progress.json` by hand. Each item's `pct` runs from 0 (not started) to 100 (done), and `note` is an optional short label such as a venue. The copy step in the page also stamps `updated`, the per-item `delta` and a `history` point. These drive the "since last update" figures and the trend line, so prefer it when you can.
